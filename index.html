X 계정 정리 도구

내 게시물·답글·좋아요·북마크를 골라서 정리합니다. 아카이브 분석과 선택은 이 페이지 안에서만 이루어지고, 파일은 어디로도 전송되지 않습니다.

시작하기 전에

  • 계정이 제한될 수 있습니다. 이 도구는 X 공식 API를 쓰지 않고, 로그인된 X 화면에서 사람이 누르는 버튼(⋯ → 삭제하기, 하트, 북마크)을 자동으로 누릅니다. X는 이런 자동화를 허용하지 않습니다. 위험을 이해하는 경우에만 사용해 주세요.
  • 되돌릴 수 없습니다. 삭제한 게시물, 취소한 좋아요, 지운 북마크는 복구되지 않습니다. 3단계에서 백업을 먼저 받아 주세요.
  • 동작하지 않을 수 있습니다. X 화면 구성이 바뀌면 실행기가 멈출 수 있습니다. 실행기의 ‘시험 실행’으로 먼저 확인해 보세요. 삭제된 게시물에 남은 좋아요는 화면에서 취소할 수 없습니다.

1아카이브 불러오기

X에서 데이터 아카이브를 요청해 받으세요(설정 → 계정 → 데이터 아카이브 다운로드, 준비에 수일이 걸릴 수 있습니다). 받은 ZIP 파일을 그대로 올리거나, 압축을 풀어 tweets.js·like.js를 선택하셔도 됩니다. 북마크만 지우실 경우에는 이 단계를 건너뛰셔도 됩니다.

    3백업하고 작업 파일 만들기

    4X에서 실행하기

    1. PC 브라우저에서 내 계정으로 로그인한 x.com 탭을 엽니다.
    2. F12(Mac은 ⌥⌘I)를 눌러 개발자 도구의 Console 탭을 엽니다.
    3. 아래 실행기 복사를 눌러 콘솔에 붙여 넣고 Enter를 누릅니다. 붙여넣기가 막혀 있으면 allow pasting을 입력하고 Enter를 누른 뒤 다시 붙여 넣습니다.
    4. 화면 오른쪽 아래에 나타난 X 정리 실행기 패널에서 3단계의 작업 파일을 선택합니다.
    5. 먼저 시험 실행을 체크하고 실행해 보세요. 실제로 지우지 않고 삭제 확인 창까지만 열었다가 취소하므로, 지금의 X 화면에서 제대로 작동하는지 확인할 수 있습니다.
    6. 시험 결과에 실패가 없으면 체크를 풀고 속도를 고른 뒤 시작합니다. 실행기가 게시물 화면을 하나씩 열며 버튼을 누르므로 1건당 몇 초가 걸립니다.
    7. 실행 중에는 탭을 닫거나 새로고침하지 말고 화면에 띄워 두세요(다른 탭으로 가면 브라우저가 속도를 크게 늦춥니다). 중단되면 같은 작업 파일을 다시 선택해 이어서 진행할 수 있습니다.
    실행기 코드 직접 확인하기

    콘솔에 붙여 넣는 코드는 계정 전체에 접근할 수 있으므로, 실행 전에 내용을 확인하시기 바랍니다. x.com 이외의 서버로는 아무것도 보내지 않습니다.
